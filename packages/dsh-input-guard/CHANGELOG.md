# Changelog

本文件记录 `@michengai/dsh-input-guard` 的变更。格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.7] - 2026-09-14

### 新增

- **内置 41 条默认词条映射**（`src/default-mappings.ts`）：内部产品名 → 水果/动物代号，装完即生效，无需任何配置。
- 默认映射作为**打底值**参与合并：本机配置与远程规则里的同名 `from` 覆盖它（可改目标或用 `enabled: false` 禁用），
  新增条目追加在后，总数仍受 200 条上限约束。

### 变更

- `mappings` 由「整体替换」改为「默认清单打底 + 同名覆盖 + 新增追加」：内置清单是基础防线，
  不应因为配置里写了别的条目就整份消失。
- 远程下发的 `mappings` 同样以默认清单打底（此前是整体替换，会让默认映射一次性全部失效）。

### 说明

- 存在包含关系时按最长优先匹配（`心水收纳` → `芹菜`，不会拆成 `洋葱收纳`）；
  ASCII 词条忽略大小写并匹配词边界，含中文的词条按子串匹配。
- 命中默认映射后 Enter 会被拦下并**静默**改写草稿，需再按一次 Enter 才会发出（与自定义映射同一路径）。

## [0.1.6] - 2026-09-14

### 新增

- **远程规则来源**：本地配置新增 `remoteUrl`，注册完成后后台拉取该地址并**远程优先**覆盖本地：
  `rules` 逐条覆盖，`terms` / `termAction` / `mappings` 整体替换。
- 配置源改为可热替换：插槽仍用本地与缓存配置**立即**注册（拦截没有真空期），远程规则到达后热替换生效，无需重启宿主。
- 远程原文缓存在独立键 `michengai.codex-ui.input-guard.remote-cache.v1`，离线或首次请求失败时沿用上次的远程效果。

### 安全

- 远程地址只接受 `https`；超时 1.5 秒、响应体上限 64 KiB，非 2xx / 非 JSON / 版本不符一律视为拉取失败，
  失败时回落本地与缓存，绝不因网络问题让拦截降级或消失。
- 远程**无权**覆盖 `maskOnSubmit` / `maskOnPaste` / `remoteUrl`，载荷里的越界字段直接忽略。
- 远程**无权**关停全部阻断规则：合并后若不存在启用的阻断规则，拒绝远程 `rules` 并保留本地规则，同时在控制台说明。
- 缓存与本地配置分键存放，远程内容不写回本地键，用户手改的配置不会被远程内容污染。

## [0.1.5] - 2026-09-14

### 变更

- **脱敏提示改为插件自绘浮层，显示 3 秒后自动隐藏**。原先用宿主 `input.notify`：该接口只把提示推进 InputNotice 列表，
  既没有超时也没有清除接口（已在 `@deepseek-ai/dsh-client-ui-conversation@0.1.5-rc.1` 的实现里确认，包内不存在与该列表相关的定时器），
  因此提示会一直挂在输入框上。现改由插件渲染浮层：
  - 显示 3 秒后自动隐藏；重复提示复用同一元素并重新计时；
  - 宿主提交成功（草稿清空）后再续期 3 秒，避免刚看清就被收走；
  - 贴在输入框上方居中，贴近视口顶部时自动退到底部，不会被裁掉；
  - 沿用宿主设计变量（`--dsw-alias-*` / `--dsw-shadow-lv4`）且全部带回退值；错误级 `role="alert"`、信息级 `role="status"`；
  - 不引入 `react-dom`（直接操作 DOM），避免给宿主模块表新增依赖。

### 说明

- 提示不再出现在宿主原生提示位置，改在输入框上方浮层。这是「定时隐藏」的代价：宿主接口无法清除已推送的提示。

## [0.1.4] - 2026-09-14

### 新增

- **Enter 放行原因一次性诊断**：每条放行分支（更早的处理器已处理 / 输入法组合中 / 相位繁忙 / 未命中规则）首次出现时输出一条
  `[michengai-input-guard] Enter 未拦截：<原因>`，繁忙分支附带 `phase / occurrences / images / menuOpen` 明细。
  同一原因只提示一次，正常聊天不会刷屏；「未命中规则」只报草稿长度，不把草稿内容写进控制台。
  用途：粘贴路径正常但 Enter 不触发时，一次即可定位卡在哪一步。

### 变更

- `compositionstart` / `compositionend` 改在 `ownerDocument` 捕获阶段监听，且 `compositionend` 无条件清除组合标志。
  此前 `composing` 一旦因组合在别处结束而未被清除，后续**所有 Enter 都会被永久放行**。

## [0.1.3] - 2026-09-14

### 修复

- **状态读取崩溃让 Enter 完全穿透（不脱敏的真正根因）**：`busy()` 直接读 `state.occurrences.length`，
  而宿主在相位切换期间会发出缺字段的中间态，于是 `TypeError: Cannot read properties of undefined (reading 'length')`
  从 keydown 处理器逃逸到 window（Uncaught）——本次 Enter 既没被拦下也没改写，宿主照常发送。
  现在插件只声明自己真正用到的状态字段并全部按可选处理（`occurrences?.length ?? 0`、`imageIds?.length ?? 0`、`draft ?? ''`、`phase` 缺失按 `plain` 处理）。
- **拦截路径异常隔离**：keydown 与 paste 处理器整体包 `try/catch`，任何内部异常都不再逃逸到宿主的按键流，
  改为放行本次并在控制台记录「拦截过程中出错，本次放行：」。粘贴后的整篇重算同样加了隔离。

## [0.1.2] - 2026-09-14

### 修复

- **词库只在类型层声明、运行时未注册**：宿主词库里没有 `michengai.inputGuard`，带 `locale` 的插槽拿不到文案，提示会退化成 `guard.blocked` 这类 key。
  现按宿主约定在 `apply` 里调用 `ctx.locale.register(NS, { zh, en })`。
- **首次「未找到输入框」被提前 return 吞掉**：`connect()` 用 `undefined === undefined` 判定「状态未变」，
  导致找不到输入框时既不打告警也不重试。现用专门的哨兵区分「尚未查找」与「查找过但没找到」。
- 插槽注册与输入框绑定改为可观测：成功打 `info`、失败打 `warn`/`error`，且插槽注册工厂内的异常就地捕获。

### 变更

- 测试文件 `guard-dock.spec.tsx` 改名为 `guard-dock.spec.ts`：包内 vitest 的 `include` 只匹配 `*.spec.ts`，
  此前 **dock 层 15 条用例从未被执行**（假绿）。包内用例数 101 → 116。

## [0.1.1] - 2026-09-14

### 修复

- **Enter 拦截可能整体失效**：按键/粘贴监听从输入框元素改到 `document` 捕获阶段。同一节点上的监听器按注册顺序执行（capture 标志不改变 target 阶段的顺序），
  宿主编辑器先于插件注册并在提交时 `preventDefault`，原实现随后读到 `defaultPrevented` 便直接放行，导致命中凭证与个人信息时也不会拦截。
- 新增三条诊断日志（bundle 已加载 / 会话未就绪 / 未找到输入框），原先这三处静默退让无法判断插件是否挂上。

### 新增

- `cn-landline`（固定电话）：要求带分隔符，并校验区号（`010`/`02x`/`0[3-9]xx`）与号码位数（7–8 位）。
- `cn-service-number`（服务号）：`400`/`800` 按「三位 + 七位」结构识别，五位短号（`95588`、`10086` 等）只认公开客服号白名单。

### 变更

- `cn-mobile` 现在容忍 `+86`/`0086` 前缀与空格、短横分组：`138 0013 8000`、`138-0013-8000`、`008613800138000` 都能脱敏，输出统一归一为 `138****8000`。

## [0.1.0] - 2026-09-11

### 新增

- 15 条内置识别规则：9 条阻断（私钥、云访问密钥、模型 API Key、代码托管令牌、Slack 令牌、Google API Key、JWT、Bearer 令牌、带口令连接串）
  与 5 条脱敏（赋值类密钥、身份证、银行卡、手机号、邮箱、内网地址），身份证走校验位、银行卡走 Luhn，压低误报。
- Enter 提交拦截：阻断类命中拦下发送并说明规则；脱敏类命中就地打码后再由用户确认。
- 粘贴拦截：阻断类命中直接取消粘贴；脱敏类先落地再按整篇草稿重算改写。
- 自定义敏感词（最多 200 条）与逐条规则开关、动作覆盖。
- 词条映射替换：`from → to` 支持 CJK 子串与 ASCII 词边界两种匹配，单次扫描、最长优先、不递归。
- 配置持久化于 `michengai.codex-ui.input-guard.v1`，损坏配置回落默认值。

### 说明

- 词条映射为**静默改写**：命中时第一次 Enter 只改写草稿，不发送、不提示，需再按一次 Enter。
- 草稿含结构化引用或图片、输入法组合中、带修饰键、触发菜单打开、宿主已处理事件时一律完全放行。
- 零运行时依赖，`react` / `react-dom` 由宿主模块表提供。
